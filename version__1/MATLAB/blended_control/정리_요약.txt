==================================================================
1. 연속 시간 모델 찾기
==================================================================
- 키네마틱스 모델 (기구학 자전거 모델, 뒤 차축 중앙 기준, L = 0.59 m)
    dx/dt = v cos(θ)
    dy/dt = v sin(θ)
    dθ/dt = v tan(δ) / L
  액추에이터
    dδ/dt = ω                  (조향: 인테그레이터)
    ds/dt = v,  dv/dt = a      (전진: 더블 인테그레이터)

- PP 알고리즘 (Pure Pursuit)
    δ_pp(t) = atan( 2 L sin(α(t)) / L_ad(t) )
      선행점: 경로를 따라 L_f 앞의 점
      α: 차 방향과 (차 → 선행점) 방향 사이 각,  L_ad: 차와 선행점 사이 거리

- PID control (횡오차 e = 0 - e_lat, 목표 - 현재)
    δ(t) = K_p e(t) + K_i ∫ e dt + K_d de/dt

==================================================================
2. 이산 모델로 바꾸기   (T_s = 0.1 s, k = 스텝 번호, t = k T_s)
==================================================================
- 키네마틱스 모델 (입력은 한 스텝 동안 일정 = ZOH → 정확한 이산식)
    [s; v; δ][k+1] = A [s; v; δ][k] + B [a; ω][k]
      A = [1 T 0; 0 1 0; 0 0 1],   B = [T^2/2 0; T 0; 0 T]
      s[k+1] = s[k] + T v[k] + T^2/2 a[k],  v[k+1] = v[k] + T a[k],  δ[k+1] = δ[k] + T ω[k]
    Δs = s[k+1] - s[k]
    x[k+1] = x[k] + Δs cos θ[k]
    y[k+1] = y[k] + Δs sin θ[k]
    θ[k+1] = θ[k] + Δs tan δ[k+1] / L
    입력 한계: a -2 ~ +1 m/s^2 (v 0 ~ 1.5 m/s), ω ±90°/s (δ ±30°)
    파일: path_model_matrices.m, path_model_step.m, bicycle_discrete_step.m

- PP 알고리즘 (매 스텝 k에서 계산)
    δ_pp[k] = atan( 2 L sin α[k] / L_ad[k] )
    조향 입력: ω[k] = (δ_cmd[k] - δ[k]) / T_s   →  δ[k+1] = δ_cmd[k]  (한 스텝 뒤 반영)

- PID control
    δ[k] = K_p e[k] + K_i Σ e[j] T_s + K_d (e[k] - e[k-1]) / T_s
    (비교용 PID: pid_steer.m, 게인 3.0 / 0.8 / 2.6)

+ tracking error plot (blended_discrete.m 그림 오른쪽)
    ① 조향각 추종 (PP_PID): 목표 δ_ref = atan(Lκ) 노랑 / 현재 δ 빨강 / δ_ref - δ 주황
    ② 조향각 오차 (δ_ref - δ)의 누적 MSE: PP 초록, PID 파랑, PP_PID 빨강
    ③ 궤적 오차 = 레퍼런스 경로 - 주행 경로 = 0 - e_lat: PP, PID, PP_PID
    맵 아래 체크박스(키 R,1,2,3,L,Y,D,E)로 각 선을 켜고 끔

4. PP_PID 블렌디드 방식으로 control하기
==================================================================
- 식
    δ_cmd[k] = Lowpass( K_pp δ_pp + δ_p + δ_i + δ_d ),   K_pp + K_p + K_i + K_d = 1
      δ_pp = atan(2 L sin α / L_ad)                          (Eq.3)
      δ_p  = K_p e_la,   e_la = e + (a + L_ad) sin Δψ         (Eq.4–6, 횡오차 + 방향 오차)
      δ_i  = K_i Σ e                                          (Eq.7, 스텝마다 더함)
      δ_d  = K_d (e[k] - e[k-1]) / T_s                        (추가한 D 항)
    Lowpass (Eq.8–9): δ_cmd[k] = w δ_raw[k] + (1 - w)/(ℓ - 1) Σ(직전 ℓ-1개 출력)
- 블렌디드 = 매 스텝 네 항을 모두 계산해서 가중합 (PP ↔ PID 전환 없음)
- 핵심 코드 (blended_steer.m)
    ela  = eLat + (g.a + Lad) * sin(dPsi);                       % 50행
    dP   = g.Kp * ela;                                            % 51행
    mem.Se = mem.Se + eLat;   dI = g.Ki * mem.Se;                 % 54–55행
    dE = (eLat - mem.ePrev) / T;   dD = g.Kd * dE;                % 58–64행
    dRaw = g.Kpp * dPP + dP + dI + dD;                            % 67행 ★ 블렌디드
    [dCmd, mem.hist] = lpf_window(mem.hist, dRaw, g.ell, g.wcur); % 68행 ★ Low pass
  이후: ω = (dCmd - δ)/T_s → bicycle_discrete_step → 다음 상태 (blended_discrete.m 245–246행)
- 기본값: L_f 0.8 m, K_p 0.01, K_i 0.006, K_d 0.001, K_pp 0.983, a 0.59 m, ℓ 3, w 0.5
- 결과 (한 바퀴, 0.8 m/s): 궤적 오차 RMS  PP 0.0118 m / PID 0.0341 m / PP_PID 0.0102 m
                           조향각 오차 RMS PP 1.96°   / PID 3.29°    / PP_PID 1.90°
- 주의: 합 = 1 규칙 때문에 이 차(오차 수 cm)에서는 P·D 항 효과가 작고, 개선은 주로 Low pass에서 옴
        (규칙 없이 K_pp 1, K_p 2, K_i 0.02, K_d 2, a 0이면 0.0063 m)
- 실행 (MATLAB 폴더에서 setup_paths 후, Unity Play 먼저)
    blended_discrete                     % 키보드: ↑를 누른 채 Space
    blended_discrete('input', 'auto')    % 자동 한 바퀴
    test_blended                         % 테스트 16개
- 실행 중 조절: 그림 왼쪽 아래 슬라이더 (v, L_f, a, w, ℓ, K_p, K_i, K_d / K_pp는 자동), 다음 스텝부터 적용
