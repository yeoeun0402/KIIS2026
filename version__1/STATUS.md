## 2. 좌표계

| 이름 | 원점 | 축 | 쓰는 곳 |
|---|---|---|---|
| **track** (기준) | 매트 왼쪽 아래 모서리, 바닥 | x 오른쪽 (16 m), y 위 (11 m), θ 는 +x 에서 반시계 | 도면, 2차선 중심선, build_map 궤적, 마커 지도, 실시간 localization, 대시보드 지도, 비교 분석 |
| **sim** (MATLAB) | 매트 가운데 | track 을 180° 돌린 것 | MATLAB 차량 모델, Unity 로 보내는 상태 |
| **Unity world** | 매트 가운데 (`mapOrigin` 없음 = 0,0,0) | X = sim x, Z = sim y, Y 위 | Unity 장면 |
| **base_link** (차) | 뒷축 중앙의 바닥 투영 | x 앞, y 왼쪽, z 위 | 차 위치의 기준점 (실차·MATLAB·Unity 모두 같음) |
| **optical** (카메라) | 렌즈 중심 | x 오른쪽, y 아래, z 앞 | ArUco 검출·자세 추정 |

**변환식**
- track ↔ sim (`MATLAB/twin/twin_frames.m`): `x_t = 8 − x_s`, `y_t = 5.5 − y_s`, `θ_t = θ_s − π` (반대 방향도 같은 식)
- sim → Unity (`CarStateReceiver.cs`): 위치 `(X, Y, Z) = (x_s, 0.037, y_s)`, 회전 `Y = 90° − yaw_s[deg]`
- 카메라 → 차 (`trackmap.py T_base_opt`): 장착값 x 0, y 0, z 0.75 m, pitch·roll·yaw (§5)

**같은 출발 자세를 각 좌표계로 쓴 값 (검증)**

| 좌표계 | 값 | 출처 |
|---|---|---|
| track | (1.265, 6.659), −90° | `~/demo/track/track.yaml start.base_link` |
| sim | (6.735, −1.159), +90° | `twin_params.m startTrack` → `twin_frames` |
| Unity | X 6.735, Z −1.159, 회전 Y 0° | `SampleScene.unity` 의 car 위치 (일치) |

## 4. 스케일 점검

| 항목 | 기준 | 측정 | 판정 |
|---|---|---|---|
| 매트 | 도면 16 × 11 m | Unity 16 × 11 m | 같음 |
| 마커 검은 사각형 | 자로 잰 17.5 cm | 설정 0.175 m (`track.yaml`, SLAM, 영상) | 같음 |
| 차선 폭 (카메라 영상 + 렌즈 높이 0.75 m, **초점거리와 무관**) | 도면 0.85 m | **0.89 m** | +4.7% |
| 마커 실효 크기 (영상: 받침 바닥 거리 ÷ 크기 거리, 초점거리와 무관) | 17.5 cm | 16.6~17.5 cm (평균 17.1) | −2% |
| build_map 궤적 → 2차선에 맞추는 배율 (마커 0.175 m) | 1.00 | 0.96 (212500), 0.95 (214854) | 궤적이 4~5% 큼 |
| 카메라 초점거리 | 보정값 fx 1481 px | build_map 추정 0.99배 (1466) | 지도 크기와 초점거리는 서로 구분 안 됨 → 이 값으로는 확인 불가 |

**결론:** 큰 문제(마커 크기 20%)는 고쳤고, **4~5% 가 남았습니다.** 두 가지가 겹친 것으로 보입니다.
- 마커로 잰 거리가 4~5% 큼 → 카메라 보정 **fx 가 약 5% 큼** 일 가능성 (fx 가 크면 같은 픽셀 크기의 마커가 더 멀리 계산됨)
- 바닥으로 잰 차선 폭이 4.7% 큼 → **렌즈 높이 (0.75 m) 또는 아래 기울기(2.5°)** 가 조금 틀렸을 가능성

확인 방법: 렌즈 중심 높이를 줄자로 재기 · 바닥에 1 m 간격 표시를 놓고 찍어 보기 · 체커보드로 카메라 다시 보정.

## 7. 남은 문제 (중요한 순)

1. **스케일 4~5%** (§4): 카메라 fx 또는 렌즈 높이·기울기. 측정으로 확인 필요.
2. **고정 지도 `live_map` 이 트랙의 32% 만 봄**: 마커 재배치 뒤 지도. 한 바퀴 전체를 돈 주행으로 다시 만들어야 위쪽 S자·오른쪽 구간이 맞음.
3. **주행을 Ctrl-C 로 끝내면 결과 영상·localization·비교가 안 만들어짐**: 지금까지 5번. Q 로 끝내야 함 (또는 Ctrl-C 에도 후처리하도록 바꿀 수 있음).
4. **Unity 편집기가 저절로 닫힘**: 3번, 충돌이 아니라 정상 종료 순서. 원인 모름.
5. **조향 센서(POT) 가 계속 0**: 실제 조향각을 못 잼. 최대 조향·조향 오프셋은 궤적에서 추정한 값 (불확실).
6. **카메라가 차 방향에서 2.7~4.2° 돌아가 있음** (지도 추정): 설정·Unity 는 0°.
7. 예전 MATLAB 모듈(test1·PID·switching)은 예전 `vehicle_params`·예전 바닥 그림 경로를 씀.
